      Как проверить совпадения?

      Способ проверки оригиналов
      Одинаковые характеристики не гарантируют одинаковое содержимое. Могут удалиться разные картинки.
      Выбранные группы

        Скопируйте решение и отправьте его в чат. Агент выполнит указанный шаг через MCP. На этой странице файлы не удаляются.

        Разбор без лишней суеты

        Узнайте картинки по миниатюрам

        Каждая карточка — группа файлов с одинаковыми характеристиками оригинала. Откройте её, чтобы увидеть имена, размеры и использование на полотнах. Сама миниатюра не доказывает совпадение.

        Выберите группы и действие

        Нажимайте кружок на карточке. Можно выбрать все найденные группы, использовать Shift для диапазона, а затем разом оставить одну копию или убрать все. Скрытые фильтром выбранные группы тоже входят в итог.

        Вы решаете, насколько тщательно проверять

        SHA-256 сравнивает байты оригиналов: потребуется их скачать. Проверка по характеристикам экономит трафик, но допускает различия. Итоговый выбор отправляется в чат; MCP выполняет проверку и подтверждает удаление.

        Защиты сохраняются при любом выборе

        Используемые на полотнах и заблокированные файлы пропускаются. При SHA-проверке сохраняются уникальные варианты; «оставить одну» действует отдельно для каждого совпавшего варианта. Оценка места учитывает известные защиты и может измениться после проверки.
